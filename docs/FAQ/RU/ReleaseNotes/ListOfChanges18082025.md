<h2>🚀 Расширение системы Webhook для работы с объектами, Отображение оборудования в списке выполненных работ, Обновлённый дизайн страницы сотрудника и заказчика - доработки от 18.08.2025</h2>
<h3><span data-teams="true">Расширение системы Webhook для работы с объектами</span></h3>
<h3>🌟 Что нового?</h3>
<p>Мы значительно расширили возможности интеграции через Webhook, добавив поддержку событий по работе с объектами. Теперь ваши системы могут мгновенно получать уведомления по событиям:</p>
<ul>
<li>Создании новых объектов (включая массовый импорт)</li>
<li>Изменениях в объектах (включая массовые правки)</li>
<li>Удалении объектов (включая массовое удаление)</li>
<li>Публикации и снятии с публикации объектов</li>
</ul>
<h3>🔧 Ключевые изменения</h3>
<h4>📌 Новые типы событий</h4>
<p>В систему добавлены 5 новых событий:</p>
<ol>
<li>Создание объекта - <em><strong>"EventID": 40</strong></em></li>
<li>Изменение объекта - <em><strong>"EventID": 41</strong></em></li>
<li>Удаление объекта - <em><strong>"EventID": 42</strong></em></li>
<li>Публикация объекта - <em><strong>"EventID": 43</strong></em></li>
<li>Снятие объекта с публикации - <em><strong>"EventID": 44</strong></em></li>
</ol>
<h4>🛠️ Обновления API</h4>
<ol>
<li><strong>/COMMON/events</strong>:
<ul>
<li>Расширенный список событий для вебхуков</li>
</ul>
</li>
<li><strong>/MSG/webhooks</strong>:
<ul>
<li>Поддержка новых типов событий</li>
</ul>
</li>
</ol>
<h2>⚡ Преимущества</h2>
<p>✅ Мгновенные уведомления об изменениях объектов<br />✅ Гибкая настройка под конкретные бизнес-процессы<br />✅ Простая интеграция через REST API</p>
<p>&nbsp;</p>
<h3><span data-teams="true">Отображение оборудования в списке выполненных работ</span></h3>
<p data-start="95" data-end="342">Теперь в мобильном и в веб приложении на вкладке <strong>"Выполнение"</strong> в карточках выполненных работ отображается не только название работы, но и оборудование, к которому она относится. Это обновление делает список выполненных работ более прозрачным и удобным для анализа.</p>

<h4 data-start="344" data-end="377">Что изменилось:</h4>
<ul data-start="381" data-end="950">
<li data-start="381" data-end="510">
<p data-start="383" data-end="510"><strong data-start="383" data-end="420">Название оборудования</strong>: теперь отображается прямо в карточке выполненной работы рядом с её названием.</p>
</li>
<li data-start="512" data-end="730">
<p data-start="514" data-end="730"><strong data-start="514" data-end="563">Прозрачность данных</strong>: в списке сразу видно связку <em>"работа → оборудование"</em>, без необходимости открывать каждую запись.</p>
</li>
<li data-start="732" data-end="950">
<p data-start="734" data-end="950"><strong data-start="734" data-end="768">Быстрее и удобнее</strong>: инженерам и диспетчерам проще ориентироваться, а клиентам — понимать, какие работы были выполнены и на каком оборудовании.</p></li>
</ul>

<h3><span data-teams="true">Обновлённый дизайн страницы сотрудника и заказчика</span></h3>
